# Dictionaries Directory

This directory contains reference dictionaries for data processing.

## Structure

- `abbreviations.csv` - Common material abbreviations and expansions
- `uom_mapping.csv` - Unit of measurement mappings
- `material_types.csv` - Standard material type classifications
- `standards.csv` - Industry standards and specifications

## Purpose

These dictionaries provide reference data for:

- Text normalization and abbreviation expansion
- Unit conversion and standardization
- Material type classification
- Standards validation

## Adding New Dictionaries

To add a new reference dictionary:

1. Create a CSV file with appropriate schema
2. Document the file structure in this README
3. Update the pipeline to use the new dictionary

## Format

Each dictionary should follow a consistent CSV format with clear headers and documentation.
