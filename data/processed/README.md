# Processed Data Directory

This directory contains processed material data after pipeline execution.

## Structure

Processed data files will be generated by the pipeline:

- `profiled_materials.csv` - Data after profiling phase
- `normalized_materials.csv` - Data after cleaning/normalization
- `extracted_attributes.csv` - Extracted material attributes
- `standardized_materials.csv` - Standardized material descriptions
- `embeddings_metadata.csv` - Embedding metadata
- `validated_matches.csv` - Validated material matches

## Generation

These files are automatically generated by the data pipeline. Do not manually edit them.

To regenerate:

```bash
python scripts/run_pipeline.py
```

## Format

All processed files follow standardized schemas defined in the pipeline configuration.
